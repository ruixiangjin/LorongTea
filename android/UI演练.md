# 南巷茶铺 Android 界面演练

## 打开演练入口

1. 用 Android Studio 打开 LorongTea 的 `android` 目录。选择 `debug` 构建和你的 Android 模拟器，运行 `app`。
2. 按模拟器 Home 键，打开应用列表，选择 **南巷茶铺 · 界面演练**。英文系统下叫 **Lorong Tea UI Lab**。
3. 演练入口可离线使用。里面的门店、订单和回执都是本地示例。Android 返回键可以退出当前场景。

## 自己走一遍

| 想检查的内容 | 操作 | 可以观察什么 |
| --- | --- | --- |
| 门店和加购 | 演练入口 → **门店与购物车** → 给炭焙乌龙加两杯 → 点右上角 **切换** → 加一杯 → 再切回 | 两店价格和购物车各自保留。留意饮品图片裁切、加购反馈和底部合计的位置 |
| 订单核对 | 在 **门店与购物车** 加购 → 点底部合计 → **核对订单** → 查看门店、饮品、合计和到店付款 → 返回 | 订单核对页信息是否容易扫读，返回后数量是否保留 |
| 改价和找回订单 | 从演练首页分别打开 **改价后的购物车** 和 **待确认购物车**。在前者核对 RM 10.90 → RM 11.90，在后者点 **找回订单** | 改价需要重新核对，待确认会打开原订单示例 |
| 查单取茶 | **订单与取茶进度** → 点屏幕上方的状态选择器，依次选 **正在制作**、**备好 · 待付款**、**备好 · 已付款**。点一次刷新 | 已付款且备好时才有取茶码。留意每一步提示是否明确，刷新时内容是否稳定 |
| 秒杀开售和门店 | **秒杀与活动回执** → 默认 **比较两店开售状态**。切换武吉免登和八打灵再也。再选 **即将开售** → **快进 20 秒** → **刷新活动状态** | 两店可分别展示可抢和售罄。倒计时归零后先刷新，状态更新后才出现 **立即抢购** |
| 秒杀回执 | 同一场景依次选 **结果待确认**、**已受理 · 等待成单**、**请求限流**。待确认和已受理可点 **查询原请求**，成单后点 **查看订单**。限流场景可点 **快进 20 秒** | 回执和成单动作分开。限流期间有等待提示，成单后沿用同一套订单详情 |
| 布局和动画 | 用上述任一场景试试横屏、系统大字号和关闭系统动画 | 检查长文字、确认按钮和取茶码在你常用的设置下是否好读、好点 |

要走真实的 Part D 下单流程，按 [项目说明](../README.zh-CN.md) 启动本地后端，打开正常的 **南巷茶铺** 并用你的本地演示账号登录。选门店后滚动菜单，切到 **订单** 再返回 **点单**，检查菜单位置是否保留。需要切店时，点菜单右上角 **切换**，选另一家店并确认。真实活动数据在 Part G 接入。
